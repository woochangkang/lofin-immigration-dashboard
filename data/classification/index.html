분류 단위는 이름×부문입니다. 같은 이름이 여러 부문에 놓인 경우가 4.4%인데 지출로는 33.0%이고, 쌍으로 세도 작업량은 6.6%만 늡니다. 부수 발견 — 민생회복 소비쿠폰이 단체에 따라 네 분야에 흩어져 있습니다. 법정 축인 부문도 단체 간 코딩이 일치하지 않습니다. 분야·부문 비교에도 이 오차가 들어 있습니다.

보류하는 축 — 법정의무/재량. 사업명만으로 판단이 어렵고 오류 비용이 큽니다.

절차와 검증

  1. 규칙 티어 — 행정운영경비·재무활동을 정규식으로 분리(LLM 제외). 적중 이름 200개 눈검사, 정책사업 오탐 0
  2. 골드샘플 200 — 부문×지출 층화, 보조/자체 반반. 코더 2인 독립 코딩 → κ 보고
  3. 코드북·프롬프트 — 골드 대비 축별 F1. 0.8 미만 축은 수정 후 재실행, 최대 3회
  4. 모델 선택 — Haiku 4.5 / Sonnet 5 / Opus 5를 골드로 비교. 근거는 F1이지 가격이 아님
  5. 안정성 — 프롬프트 변형 3 × 반복 3, 일치율 ≥ 0.9, temperature 0
  6. 2차 주제 귀납 — 상위 7개 부문, 각 5–15개, 잔여 ≤ 15%
  7. 실행 — 상위 1만 → 전수(배치 8개). 체크포인트, raw 응답 전량 보존
  8. 전파·보고 — 이름 → 코드 → 행. 지출 총액 보존 확인. 프롬프트 전문·모델 ID·κ·F1 공개
