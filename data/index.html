이 페이지는 데이터베이스가 어떻게 만들어졌는지를 재현 가능한 수준으로 기록합니다. 모든 수치는 수집·검증 시점(2026-09-02)의 실측값입니다.

1. 출처와 접근 경로

원자료는 지방재정365 오픈API의 세부사업별 세출현황(요청주소 lofin365.go.kr/lf/hub/QWGJK)입니다. 공공데이터포털에도 같은 항목이 등록돼 있지만 API 유형이 LINK여서 포털 인증키로는 호출할 수 없고, 지방재정365 회원가입 후 발급받는 자체 인증키를 씁니다.

2. 수집 파이프라인

  1. 01 수집 — 연도 × 단체 × 페이지 루프. 응답 원문(JSON)을 그대로 저장하고, 파일마다 SHA-256·행수·totalCount를 매니페스트에 기록. 단체 단위 완료 마커로 중단 후 재개 가능. 결과: 5,563개 파일, 원본 2.2 GB.
  2. 02 적재 — 원본을 연도별 Parquet(zstd)로 변환한 뒤 DuckDB 테이블 settle_dtl로 통합. 금액은 원 단위 정수, 코드는 문자열로 고정.
  3. 04 검증 — 단체·연도 2,430건 각각에 대해 API totalCount = 매니페스트 행수 = DB 행수 3자 대조. 불일치 0건.
  4. 05 주제 분류 — 사업명 키워드 규칙과 사업코드 단위 연결로 주제별 사업 집합 구성(방법 페이지).
  5. 06–08 산출 — 경계 데이터 투영, 코드·명칭 매핑, 이 사이트 빌드. 원본은 수정하지 않으며 모든 변환은 스크립트로만 수행합니다.

5. 세부사업코드의 구조

16자리 코드 101만 개를 전수 검증한 결과, 행정자치단체코드(7) + 사업 개설연도(4) + 일련번호(5)로 구성됩니다. 앞 7자리는 행정자치단체코드와 95.9% 일치하고, 8~11자리는 100%가 연도 형식이며 100%가 해당 사업의 최초 관측 연도보다 이르거나 같습니다(2016년 이후 개설 사업은 67.7%가 정확히 일치 — 나머지는 관측 시작 전 개설). 따라서 사업 신설 시점을 코드만으로 추적할 수 있습니다. 뒷 5자리는 위계 정보가 없는 일련번호입니다.

같은 코드는 같은 사업으로 취급합니다. 사업명이 연도에 따라 바뀌어도(약 19%의 코드가 관측 기간 중 개명) 코드로 연결하며, 2023년 군위군의 대구 편입처럼 자치단체가 바뀐 경우에도 코드가 유지되어 시계열이 끊기지 않습니다.

6. 한계

  • 스냅샷 자료: 12월 31일 기준 집행 현황이며 출납폐쇄기간 정리분이 반영된 값입니다. 공식 결산서 수치와 미세하게 다를 수 있습니다.
  • 세부사업이 최소 단위: 사업 내부의 비목(운영비·시설비 등)은 보이지 않습니다. 건립·리모델링은 대개 별도 세부사업으로 편성되므로 이름으로 식별합니다.
  • 보조금 흐름: 광역이 기초에 보조하면 양쪽 모두 지출로 기록될 수 있어, 시도 합계에는 이중 계상 가능성이 있습니다. 단체 수준 분석에는 영향이 없습니다.
  • 경계 데이터: 지도는 KOSTAT 2013 경계를 쓰며 청원군→청주시 통합, 인천 남구→미추홀구 개칭, 군위군 편입을 연도별로 처리했습니다.

7. 갱신

결산이 확정되는 매년 하반기에 새 회계연도 하나를 추가합니다. 수집 스크립트는 연도 인자만 받으므로 한 연도 수집 → 적재 → 검증 → 주제 분류 재실행 → 사이트 재빌드 순서로 끝납니다. 모든 스크립트와 분류 사전은 로컬 연구 저장소에서 버전 관리하며, 이 사이트는 산출물만 담습니다.
