# 지방정부 이민·다문화 재정 지출 대시보드 (2016–2025)

행정안전부 [지방재정365](https://www.lofin365.go.kr) 「세부사업별 세출현황」 오픈API로 수집한
243개 자치단체 × 10개 회계연도 전수 자료(429만여 행)에서, 사업명에 이민·다문화·외국인 대상이
명시된 세부사업을 추출해 정리한 정적 대시보드입니다.

**Live**: https://woochangkang.github.io/lofin-immigration-dashboard/

## 내용

- 연도별 지출 추이 (확정/분류보류 구분)
- 재원 구성 (국비·시도비·시군구비)
- 시도별 분포 (총지출 대비 비중 히트맵 + 선택 연도 지출액)
- 10년 누적 상위 세부사업
- 자치단체별 내역 테이블 (연도 선택·검색·정렬)

## 측정 정의

"사업명에 명시적으로 표적화된 이민·다문화·외국인 지출"만 포함
(다문화, 이주민, 결혼이민, 귀화, 외국인주민, 외국인근로자, 계절근로 등).
외국인 *투자*·*관광*·*환자유치* 사업은 규칙으로 배제. 사업명에 드러나지 않는
통합 예산은 포착하지 못하므로 **하한 추정치**입니다.

## 데이터

- 출처: 행정안전부 지방재정365 오픈API (이용조건: 출처표시·상업적/비상업적 이용 및 2차 저작 가능)
- 기준: 회계연도별 12월 31일 집행 스냅샷 (출납폐쇄기간 정리분 반영), 금액 단위 원
- 수집·검증: 2026-09-02. 단체·연도 2,430건 전부 API totalCount = 매니페스트 = DB 행수 일치 확인

수집·분류 파이프라인은 로컬 연구 저장소에서 관리하며, 이 저장소는 산출물(단일 `index.html`,
집계 데이터 인라인)만 담습니다.
