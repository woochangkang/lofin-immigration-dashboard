# 지방재정 세부사업 데이터

행정안전부 [지방재정365](https://www.lofin365.go.kr) 「세부사업별 세출현황」을 전수 수집해 구축한
연구용 데이터베이스(243개 자치단체 × 2016–2025, 429만여 행)와 그 위의 주제별 분석을 공개하는 정적 사이트.

**Live**: https://woochangkang.github.io/lofin-immigration-dashboard/

## 구조

자료 층과 주제 층을 분리해, 새 주제는 `/<topic>/` 아래 같은 세 페이지(전체 요약·시군구별·방법)로 추가한다.

| 경로 | 내용 |
|---|---|
| `/` | 자료 소개 — 개요, 페이지 안내, 주제 목록, 갱신 이력, 출처·인용 |
| `/data/` | 자료 수집·구축 과정 — API 명세, 파이프라인, 검증 결과, 보유 필드, 사업코드 구조, 한계, 갱신 |
| `/immigration/` | 이민·다문화 재정 — 전체 요약 (추이·재원·대상 집단 구성·시도별·대표 사업) |
| `/immigration/regions/` | 시군구별 — 시도→시군구 드릴다운 지도, 단체 요약 패널, 전체 테이블 (`#laf=코드`로 단체별 주소 공유) |
| `/immigration/methods/` | 분류 방법과 검증 — 키워드 사전, 배제 규칙, 3분류, 코드 단위 연결, 골드샘플 검증 설계 |
| `/immigration/methods/codes/` | 코드·명칭 이력 검토 — 지출 상위 100개 사업의 연도별 명칭 변화 |

## 측정 정의 (이민·다문화 재정)

사업명에 이민·다문화·외국인 주민 대상이 명시된 세부사업의 지출을, 같은 세부사업코드의 전 기간으로 연결한 값.
통합형 기관(가족센터 등)은 상한 방향, 사업명에 드러나지 않는 예산은 하한 방향의 오차 요인.
외국인 *투자*·*관광*·*환자유치* 사업과 문자열 우연(고려인삼 등)·토지보상 "이주민"은 배제.

## 데이터

- 출처: 행정안전부 지방재정365 오픈API (출처표시 하 상업적/비상업적 이용 및 2차 저작 허용)
- 기준: 회계연도별 12월 31일 집행 스냅샷(출납폐쇄기간 정리분 반영), 금액 단위 원
- 검증: 단체·연도 2,430건 전부 API totalCount = 매니페스트 = DB 행수 일치 (2026-09-02)

수집·분류 파이프라인과 사이트 빌드 스크립트는 로컬 연구 저장소에서 관리하며, 이 저장소는 빌드 산출물만 담는다.
